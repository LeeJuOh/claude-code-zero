# Harness Engineer Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the harness-engineer plugin with Layer 1 (`/harness init` scaffolding + `/harness organize` knowledge onboarding) and Layer 2 (hooks for principle enforcement).

**Scope:** Phase 1 targets P4 (.harness/map.md as index), P7 (architecture boundary enforcement), P12 (evaluator separation via Stop agent hook), P16 (harness staleness). The following Layer 2 features are deferred to Phase 1.5: P14 (context budget enforcement), PostToolUse(Bash) linter hook. Config templates include placeholders for these (`context_budget_percent`) so Phase 1.5 can add enforcement without config migration.

**Architecture:** Claude Code plugin with two skills (`init` and `organize`), two command hook scripts (`session-start-check.sh`, `pre-write-guard.sh`), and one agent hook (Stop QA gate). Hook scripts share a library (`lib.sh`) for stdin parsing, subagent detection, config loading, and **structured hook output** (`harness__deny`, `harness__allow`, `harness__ask`). PreToolUse hooks use `permissionDecision: "deny"` to **block** tool calls (not warn). Stop agent hook uses `ok: false` to **block** task completion until tests/lint pass. The init skill guides Claude through repo analysis → .harness/map.md generation → CLAUDE.md @import injection → approval → scaffolding. The organize skill onboards existing domain knowledge into the harness structure via content-based classification.

**Map architecture (agent-harness bootstrap pattern):** `.harness/map.md` is the single source of truth (platform-agnostic). `CLAUDE.md` contains `@.harness/map.md` import for CC native auto-loading. This survives context compaction. Existing CLAUDE.md files get a `<!-- harness:start/end -->` marker section. Cross-platform export (AGENTS.md, GEMINI.md) deferred to Phase 1.5.

**Hook design (verified against CC official docs + ecosystem research 2026-03-29):**
- PreToolUse hooks use `permissionDecision: "deny"` to **block** tool calls, not `additionalContext` (warning). Confirmed by gstack `/freeze` pattern + CC official docs.
- PreToolUse `if` field does NOT support pipe alternation → Write/Edit need separate hook entries
- Architecture boundary checks use command hooks (agent hooks too expensive per-write)
- Stop agent hook (`type: "agent"`) spawns a subagent to verify tests/lint/map.md sync. Returns `ok: false` to block completion.
- Stop hooks MUST check `stop_hook_active` to prevent infinite loops
- HTML comments in CLAUDE.md are stripped before injection → markers are for tool use only
- `hook_strictness` in config.yaml controls behavior: strict/standard = deny + Stop QA gate, lenient = ask + no Stop gate

**Tech Stack:** Bash (hooks), Markdown (skill), YAML (config), jq (JSON parsing)

Create `plugins/harness-engineer/hooks/lib.sh`:

```bash
#!/usr/bin/env bash
# harness-engineer: shared hook library
#
# Usage:
#   source "$(dirname "$0")/lib.sh"
#   harness__init              # reads stdin, exits if subagent
#   harness__get '.field'      # extract JSON field from input
#   harness__estimate_tokens N # bytes → approximate token count
#   harness__read_config file key default  # read flat YAML value
#   harness__deny "reason"     # PreToolUse: block tool call (permissionDecision: deny)
#   harness__ask "reason"      # PreToolUse: ask user (permissionDecision: ask)
#   harness__output "message"  # SessionStart/PostToolUse: inject context (additionalContext)

set -uo pipefail

# --- JSON field extraction (jq required) ---

harness__get() {
  echo "$HARNESS_INPUT" | jq -r "$1 // empty" 2>/dev/null
}

# --- Token estimation (bytes / 4) ---

harness__estimate_tokens() {
  local bytes="${1:-0}"
  echo $(( bytes / 4 ))
}

# --- Flat YAML config reader ---
# Reads "key: value" from a flat YAML file. No nesting support.

harness__read_config() {
  local file="$1" key="$2" default="$3"
  if [[ ! -f "$file" ]]; then
    echo "$default"
    return
  fi
  local value
  value=$(grep "^${key}:" "$file" 2>/dev/null | head -1 | sed "s/^${key}:[[:space:]]*//" | sed 's/[[:space:]]*$//')
  if [[ -z "$value" ]]; then
    echo "$default"
  else
    echo "$value"
  fi
}

# --- Hook output (3 modes) ---

# PreToolUse: block the tool call
harness__deny() {
  local reason="$1"
  jq -n --arg r "$reason" '{hookSpecificOutput: {hookEventName: "PreToolUse", permissionDecision: "deny", permissionDecisionReason: $r}}'
}

# PreToolUse: ask the user
harness__ask() {
  local reason="$1"
  jq -n --arg r "$reason" '{hookSpecificOutput: {hookEventName: "PreToolUse", permissionDecision: "ask", permissionDecisionReason: $r}}'
}

# SessionStart/PostToolUse: inject context (informational, cannot block)
harness__output() {
  local message="$1"
  jq -n --arg msg "$message" '{"additionalContext": $msg}'
}

# --- Globals ---

HARNESS_INPUT="${HARNESS_INPUT:-}"
HARNESS_CWD=""

# --- Init (reads stdin, detects subagent) ---
# Pass --no-init to skip (for testing)

harness__init() {
  HARNESS_INPUT=$(cat)

  if [[ -z "$HARNESS_INPUT" ]]; then
    exit 0
  fi

  # Subagent detection: skip in non-user sessions
  local agent_type
  agent_type=$(harness__get '.agent_type')
  if [[ -n "$agent_type" ]]; then
    exit 0
  fi

  HARNESS_CWD=$(harness__get '.cwd')
  if [[ -z "$HARNESS_CWD" ]]; then
    HARNESS_CWD="$PWD"
  fi
}

# Auto-init unless --no-init passed (for sourcing in tests)
if [[ "${1:-}" != "--no-init" ]]; then
  harness__init
fi
```

```bash
#!/usr/bin/env bash
set -uo pipefail

# harness-engineer: SessionStart hook
#
# Checks on session start (only if .harness/ exists):
# 1. .harness/map.md token count vs threshold (P4)
# 2. Evaluator agent presence in agents/ (P12)
# 3. Harness review staleness (P16)
#
# Silent when: no .harness/ (plugin not initialized), or all checks pass.

source "$(dirname "$0")/lib.sh"

# Only run if harness is initialized
HARNESS_DIR="$HARNESS_CWD/.harness"
if [[ ! -d "$HARNESS_DIR" ]]; then
  exit 0
fi

CONFIG="$HARNESS_DIR/config.yaml"
WARNINGS=()

# --- Check 1: .harness/map.md token count (P4) ---

AGENTS_MD="$HARNESS_CWD/.harness/map.md"
if [[ -f "$AGENTS_MD" ]]; then
  AGENTS_BYTES=$(wc -c < "$AGENTS_MD")
  AGENTS_TOKENS=$(harness__estimate_tokens "$AGENTS_BYTES")
  TOKEN_LIMIT=$(harness__read_config "$CONFIG" "agents_md_token_limit" "3000")
  if [[ "$AGENTS_TOKENS" -gt "$TOKEN_LIMIT" ]]; then
    WARNINGS+=("[P4] .harness/map.md: ~${AGENTS_TOKENS} tokens (limit: ${TOKEN_LIMIT}). Map, not encyclopedia. Move details to docs/.")
  fi
fi

# --- Check 2: Evaluator agent presence (P12) ---

AGENTS_DIR="$HARNESS_CWD/agents"
HAS_REVIEWER=false
if [[ -d "$AGENTS_DIR" ]]; then
  for f in "$AGENTS_DIR"/*.md; do
    [[ -f "$f" ]] || continue
    if grep -qiE '(reviewer|evaluator|judge)' "$f" 2>/dev/null; then
      HAS_REVIEWER=true
      break
    fi
  done
fi
if [[ "$HAS_REVIEWER" == "false" ]]; then
  WARNINGS+=("[P12] No evaluator agent in agents/. Self-evaluation bias risk. Run /harness init to create one.")
fi

# --- Check 3: Harness review staleness (P16) ---

LAST_REVIEWED=$(harness__read_config "$CONFIG" "last_reviewed" "")
REVIEW_INTERVAL=$(harness__read_config "$CONFIG" "review_interval_days" "90")
if [[ -n "$LAST_REVIEWED" ]]; then
  LAST_EPOCH=$(date -j -f "%Y-%m-%d" "$LAST_REVIEWED" "+%s" 2>/dev/null || date -d "$LAST_REVIEWED" "+%s" 2>/dev/null || echo "0")
  NOW_EPOCH=$(date "+%s")
  DAYS_SINCE=$(( (NOW_EPOCH - LAST_EPOCH) / 86400 ))
  if [[ "$DAYS_SINCE" -gt "$REVIEW_INTERVAL" ]]; then
    WARNINGS+=("[P16] Harness not reviewed for ${DAYS_SINCE} days (interval: ${REVIEW_INTERVAL}). Models improve — unnecessary scaffolding may exist.")
  fi
fi

# --- Output ---

if [[ ${#WARNINGS[@]} -eq 0 ]]; then
  exit 0
fi

MESSAGE="[harness-engineer] Session checks:"
for w in "${WARNINGS[@]}"; do
  MESSAGE="${MESSAGE}\n- ${w}"
done

harness__output "$(echo -e "$MESSAGE")"
```

```bash
#!/usr/bin/env bash
set -uo pipefail

# harness-engineer: PreToolUse(Write|Edit) hook
#
# Guards .harness/map.md writes:
# - Write: estimates token count of new content
# - Edit: checks existing file size (Edit doesn't provide full content)
# - Warns if exceeding threshold (P4: .harness/map.md as table of contents)
#
# Silent when: not writing .harness/map.md, or within threshold, or no .harness/.

source "$(dirname "$0")/lib.sh"

# Only run if harness is initialized
HARNESS_DIR="$HARNESS_CWD/.harness"
if [[ ! -d "$HARNESS_DIR" ]]; then
  exit 0
fi

# Check if writing to .harness/map.md
FILE_PATH=$(harness__get '.tool_input.file_path')
if [[ -z "$FILE_PATH" ]]; then
  exit 0
fi

# Normalize: check if path ends with .harness/map.md
if [[ "$FILE_PATH" != *".harness/map.md" ]]; then
  exit 0
fi

CONFIG="$HARNESS_DIR/config.yaml"
TOKEN_LIMIT=$(harness__read_config "$CONFIG" "agents_md_token_limit" "3000")

# Detect tool type: Write has .tool_input.content, Edit has .tool_input.old_string
CONTENT=$(harness__get '.tool_input.content')

if [[ -n "$CONTENT" ]]; then
  # Write tool: estimate from new content
  CONTENT_BYTES=$(echo -n "$CONTENT" | wc -c | tr -d ' ')
  CONTENT_TOKENS=$(harness__estimate_tokens "$CONTENT_BYTES")
else
  # Edit tool: estimate from existing file size (Edit only sends old_string/new_string, not full content)
  if [[ -f "$FILE_PATH" ]]; then
    EXISTING_BYTES=$(wc -c < "$FILE_PATH" | tr -d ' ')
    CONTENT_TOKENS=$(harness__estimate_tokens "$EXISTING_BYTES")
  else
    exit 0
  fi
fi
```
